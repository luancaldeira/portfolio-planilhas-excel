# Portfólio de Planilhas Excel

Coleção de cinco modelos desenvolvidos para demonstrar experiência prática em automação, análise e organização de dados no Excel. Todos os arquivos usam dados fictícios, criados apenas para demonstração.

## Projetos

| Arquivo | Caso de uso | Competências demonstradas |
| --- | --- | --- |
| `01_financial-forecast.xlsx` | Forecast financeiro e fluxo de caixa | Cenários, premissas, fórmulas, auditoria e dashboard |
| `02_sales-pipeline.xlsx` | Pipeline comercial e comissões | Forecast ponderado, validação de dados e acompanhamento de vendas |
| `03_marketing-performance.xlsx` | Performance de campanhas | CPL, ROAS, consolidação de canais e gráficos |
| `04_inventory-planning.xlsx` | Reposição de estoque | Ponto de reposição, estoque de segurança e alertas operacionais |
| `05_project-budget.xlsx` | Orçamento e previsão de projeto | Orçado versus realizado, forecast e variações |

## Como avaliar

Abra cada arquivo em Microsoft Excel. Os campos em amarelo indicam entradas alteráveis e os dashboards atualizam com as fórmulas do modelo. Os dados são fictícios e não representam resultados de empresas reais.

## Uso em cold emails

Use o link deste repositório como prova de trabalho: cada exemplo mostra um cenário de negócio diferente, fórmulas rastreáveis e uma visualização clara para tomada de decisão.
